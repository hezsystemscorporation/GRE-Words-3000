# GRE-Words-3000

This is a website built for GRE 3000 words where you can view anywhere. 
Of course, basic function including reviewing table on your PC panel and flash cards mode on your phone are provided. 

**Recent Update**: Some minor bug fixes and updated pronunciation function in English and American accents.  

As it is a single webpage without data persistence functionalities, we allow you to export words list that you want to make notes by ticking them, you can also export and import your progress via a .flag file (simple marking the word you want to flag and export it). 

*Also, the code that can parse the xlsx list into html code is also attached, so that you can easily generate a page like this for any word revision tasks.*

Thanks for the word list provided at [https://github.com/liurui39660/3000](https://github.com/liurui39660/3000).
